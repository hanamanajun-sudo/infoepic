## **JFIF 파일이란?**

JFIF는 JPEG File Interchange Format의 약자로, JPG와 동일한 이미지 형식이다. 크롬이 이미지를 저장할 때 MIME 타입을 읽어서 확장자를 자동으로 붙이는데, 특정 상황에서 .jpg 대신 .jfif가 붙는다. 파일 내용 자체는 jpg와 완전히 같다.

## **방법 1 — 파일명 확장자 직접 바꾸기 (가장 빠름)**

황당하지만 그냥 확장자를 .jpg로 바꾸면 된다. 파일 내용이 동일하기 때문에 확장자만 바꿔도 정상적으로 열린다.

윈도우에서 확장자가 안 보인다면: 파일 탐색기 → 보기 → 파일 이름 확장명 체크

여러 개를 한꺼번에 바꿔야 한다면:

[확장자 한꺼번에 바꾸기 (프로그램 필요 없이 일괄변경)](https://infoepic.com/entry/확장자-한꺼번에-바꾸기-프로그램-필요-없이-일괄변경)

## **방법 2 — 그림판으로 열어서 다른 이름으로 저장**

프로그램 설치 없이 윈도우 기본 기능으로 해결된다.

1. jfif 파일을 그림판으로 열기
2. 파일 → 다른 이름으로 저장 → JPEG 선택
3. 저장

이 방법은 확장자만 바꾸는 게 아니라 파일 자체를 jpg로 재저장하는 방식이다. 화질 설정을 높게 유지하면 변환 전후 차이가 거의 없다.

## **방법 3 — 온라인 변환 사이트**

여러 개를 한꺼번에 올려서 변환하고 싶다면:

[anyconv.com jfif→jpg 변환](https://anyconv.com/ko/jfif-to-jpg-byeonhwangi/)

파일을 한꺼번에 올리고 변환해 준다. 다운로드는 파일 하나씩 눌러야 하지만, 파일 수가 많을 때 유용하다.

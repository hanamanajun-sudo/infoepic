유튜브 채널이름 정할 때 해외 트래픽도 생각하는 분 중에 이름을 어떻게 지어야 할까 고민하는 분들 있으시죠? 저도 그랬는데 이럴 때 보통 채널 이름 앞에는 한글, 뒤에는 영어로 설정하는 사람들이 많이 있어요.

근데 이렇게 하지 않고 한국에서는 한국어로, 외국에서는 영어로 (그 외 여러 나라 언어로 가능) 설정이 가능합니다.

> ※ 이 글은 2019년 작성됐습니다. YouTube Studio UI가 이후 변경됐을 수 있으며, 현재는 **YouTube Studio → 맞춤설정 → 기본 정보** 탭에서 번역 이름을 설정할 수 있습니다.

## 설정 방법 (단계별)

유튜브 페이지에 로그인한다.

![유튜브 채널 이름 설정 방법 이미지 1](/images/youtube-name/img-1.jpg)

페이지 상단 오른쪽 본인 채널 이미지를 클릭한다.

![유튜브 채널 이름 설정 방법 이미지 2](/images/youtube-name/img-2.jpg)

메뉴 중에 내 채널 클릭

![유튜브 채널 이름 설정 방법 이미지 3](/images/youtube-name/img-3.jpg)

채널 맞춤 설정 클릭

![유튜브 채널 이름 설정 방법 이미지 4](/images/youtube-name/img-4.jpg)

톱니 바퀴 클릭

![유튜브 채널 이름 설정 방법 이미지 5](/images/youtube-name/img-5.jpg)

(그럼 다 왔습니다.) 밑에 정보 번역 란의 **채널 정보를 번역** 클릭

![유튜브 채널 이름 설정 방법 이미지 6](/images/youtube-name/img-6.jpg)

번역할 언어 선택 (영어 이외에도 검색하면 다양한 언어 선택 가능)

![유튜브 채널 이름 설정 방법 이미지 7](/images/youtube-name/img-7.jpg)

![유튜브 채널 이름 설정 방법 이미지 8](/images/youtube-name/img-8.jpg)

채널 이름 뿐 아니라 채널 설명도 번역 가능하니까 하는 김에 이 부분도 하면 좋겠죠?

그냥 한꺼번에 써도 되는데 하시는 분도 있겠지만, 한글로 분명하게 채널 이름이 있을 때와 뒤에 영어가 길게 늘어져 있을 때 시선을 끄는 정도는 다르다고 생각합니다. 해외를 염두에 두고 계신 분들의 경우 한글보다는 영어 이름으로 보이는 것이 눈에 잘 띄일 것 같기도 합니다.

유튜브 채널 테스트로 하나 개설 중에 발견한 꿀팁이어서 공유합니다. 많은 유튜버들이 이거 모르고 있는데 먼저 한번 사용해 보세요.

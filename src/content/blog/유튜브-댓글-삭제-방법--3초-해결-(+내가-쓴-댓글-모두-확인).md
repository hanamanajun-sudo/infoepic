예전에 댓글 달아놓고 나중에 다시 보니 좀 부끄러운 내용이 있어서 삭제하려고 찾아봤다. 그런데 댓글에 삭제 버튼이 없어서 잠깐 당황했다. 찾아보니 방법이 생각보다 간단했고, 내가 쓴 댓글들을 한꺼번에 관리하는 방법도 있었다.

**\* 참고:** 스마트폰 유튜브 앱에서는 댓글 삭제가 안 된다. PC 브라우저에서 해야 한다.

## **유튜브 댓글 삭제 방법**

**1. 유튜브 화면 상단 왼쪽 햄버거 버튼 클릭**

![유튜브 댓글 삭제 방법 이미지 1](/images/유튜브-댓글-삭제-방법--3초-해결-(+내가-쓴-댓글-모두-확인)/img.png)

**2. 왼쪽 메뉴 바에서 시청기록 클릭**

![유튜브 댓글 삭제 방법 이미지 2](/images/유튜브-댓글-삭제-방법--3초-해결-(+내가-쓴-댓글-모두-확인)/img_1.png)

**3. 시청기록 페이지 오른쪽 메뉴에서 댓글 클릭**

![유튜브 댓글 삭제 방법 이미지 3](/images/유튜브-댓글-삭제-방법--3초-해결-(+내가-쓴-댓글-모두-확인)/img_2.png)

**4. 내가 작성한 댓글 목록에서 X 눌러 삭제**

내가 그동안 작성한 모든 댓글이 여기 모여 있다. X를 누르면 바로 삭제된다.

![유튜브 댓글 삭제 방법 이미지 4](/images/유튜브-댓글-삭제-방법--3초-해결-(+내가-쓴-댓글-모두-확인)/img_3.png)

## **알아두면 좋은 것들**

**삭제 후 복구 불가:** 삭제하면 되돌릴 수 없다. 중요한 대화가 오간 댓글이라면 삭제 전 스크린샷을 찍어두자. 답글이 달려 있어도 같이 사라지거나 "삭제된 댓글"로 표시된다.

**위 방법이 안 될 때:** 유튜브 UI가 자주 바뀌기 때문에 경로가 달라져 있을 수 있다. 그럴 땐 **studio.youtube.com** 에 직접 접속해서 왼쪽 메뉴 → 댓글 탭으로 가면 된다.

**YouTube Studio 활용:** 유튜브 오른쪽 상단 프로필 사진 클릭 → YouTube Studio 선택, 또는 studio.youtube.com 직접 접속. 채널이 없어도 구글 계정으로 로그인하면 입장 가능하다. 내가 단 댓글 전체를 한 화면에서 확인하고 삭제할 수 있어서, 예전에 어떤 영상에 댓글 달았는지 기억이 안 날 때도 유용하다.

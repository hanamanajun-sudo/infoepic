자주 사용하는 특수문자 모음이다. 필요한 기호를 클릭해서 복사(Ctrl+C 또는 길게 누르기) 후 카카오톡, 인스타그램, 유튜브 제목, SNS 닉네임 등 어디서나 붙여넣기 하면 된다. 유니코드 기반이라 거의 모든 기기에서 표시된다.

특수문자가 필요할 때마다 매번 검색하다가 이런 모음이 있으면 좋겠다 싶었다. 특히 화살표나 음표 같은 건 어떻게 입력하는지 몰라서 그냥 복사해서 쓰는 경우가 많았는데, 여기서 한 번에 찾을 수 있도록 정리했다.

## **특수문자 입력하는 다른 방법**

매번 여기서 복사하기 번거롭다면 아래 방법을 알아두면 편하다.

- **윈도우:** `Win + .` 단축키 → 이모지·특수문자 패널 오픈 → 텍스트 아이콘 탭에서 검색 후 입력 가능
- **Mac:** `Ctrl + Cmd + Space` → 비슷한 이모지 패널 오픈
- **윈도우 한글 입력기:** 한글 자음(예: ㅁ) 입력 후 한자 키 → 특수문자 목록 표시

자주 쓰는 특수문자는 메모 앱이나 텍스트 파일에 모아두면 필요할 때 빠르게 복사해서 쓸 수 있다.
